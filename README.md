# dsubedi.info

Source for my personal academic website, published with GitHub Pages at
[dsubedi.info](https://dsubedi.info).

## Layout

| Path | Contents |
| --- | --- |
| `index.html` | The whole site: bio, news, publications, reports, contact panel |
| `stylesheet.css` | Styles, including the contact panel and its expanded card |
| `data/` | Papers, posters and presentations linked from the page |
| `images/` | Figures and profile photos |
| `CNAME` | Custom domain for GitHub Pages |

## Contact form

The contact panel posts to [Web3Forms](https://web3forms.com), which relays the
message to an alias on this domain. No email address appears in the markup. The
access key in `index.html` is public by design and is not a secret; it only
permits submitting the form.
